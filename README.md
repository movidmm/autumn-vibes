# autumn-vibes
Autumn Vibes 🍂– Coffee Shop Website

Autumn Vibes este un site de prezentare pentru o cafenea fictivă, cu un design cozy, inspirat de toamnă. Site-ul conține informații despre cafenea, un meniu cu produse și prețuri și o secțiune de contact. A fost realizat folosind HTML5 și CSS3, cu ajutorul AI.

Modificări realizate

Am schimbat diverse culori, de exemplu culoarea de fundal a secțiunii de meniu într-o nuanță mai caldă, am modificat culoarea prețurilor și am ajustat efectul hover al cardurilor, astfel încât acestea să se ridice mai puțin când trecem cu mouse-ul peste ele. De asemenea, am înlocuit mai multe imagini care nu se afișa corect.
